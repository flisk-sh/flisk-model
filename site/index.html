A small model. On purpose.

The intern, not the genius.

Inference serves flisk-wolf, a small model for small jobs: read this, return that, as JSON, fast and cheap. It will not write your novel or reason about your startup. It will fix your config at 3 a.m. for a fraction of a cent.

See 10 jobs

Why small is the pitch

Most agent traffic is boring: classify, extract, route, repair. Sending it to a frontier model is paying a surgeon to apply a plaster.

Cheap per job

A 7B-class model answers a config request in about 50 output tokens. Pricing is not set yet; see the console for the placeholder plan.

Narrow and checked

Every claim on this page names how it was tested. Where we have no test, we say so.

OpenAI-compatible

Change the base URL and the key. Your SDK, agent framework or MCP server keeps working.

Runs where you want

Hosted, or the same model on your own machine through a local server. Same API either way.

10 jobs for a small model

Status uses the same words as the Flisk roadmap: Adopt means we measured it, Assess means we think it fits and have not tested it yet.

Adopt · tested

1. Write a config

Turn a plain-English request into a valid Flisk service.json. 20 of 20 held-out and stack tasks passed on the 7B base.

Adopt · tested

2. Repair a rejected config

Feed it the validator error and the broken file; get the smallest fix back. 5 of 5.

Assess · untested

3. Route support tickets

Label each ticket billing, bug or how-to and pick the queue. A cheap first hop before a human or a big model.

Assess · untested

4. Extract fields to JSON

Invoices, emails and receipts into a fixed schema: vendor, date, total.

Assess · untested

5. Triage log lines

Mark a stack trace as noise, known issue or page-someone.

Assess · untested

6. Agent router

Decide whether a request needs a tool, a big model or a canned answer, then hand it on.

Assess · untested

7. Tag and summarise short docs

One-line summaries and tags for notes, tickets and changelog entries.

Assess · untested

8. Normalise messy input

Names, addresses, units and dates into one clean format.

Assess · untested

9. Draft commit and PR titles

Short, conventional titles from a diff stat or a file list.

Assess · untested

10. Make test data

Synthetic rows and fixtures that match a schema, for demos and tests.

One endpoint

curl https://inference.flisk.si/v1/chat/completions \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flisk-wolf",
    "messages": [{"role":"user",
      "content":"Write a Flisk service.json for a worker called emailer in the shop stack."}]
  }'
How it was tested

Scored with the Flisk CLI's own validator, temperature 0, on tasks the prompt was never tuned on. Sets, scripts and results live in the open flisk-model repo. Small models make small mistakes: it once called a one-shot job a migrator. We fixed the prompt and wrote down that we did.

Mockup for a working brand. Planned host: inference.flisk.si (site and console), with the API at inference.flisk.si/v1. Not live yet; pricing and hosting are not decided.

Inference API

OpenAI-compatible chat completions for flisk-wolf. Point an OpenAI SDK at the base URL and use your key.

from openai import OpenAI

client = OpenAI(base_url="https://inference.flisk.si/v1", api_key="fi-...")
r = client.chat.completions.create(
    model="flisk-wolf",
    messages=[{"role": "user", "content": "Write a Flisk service.json for a backend called api."}],
)
print(r.choices[0].message.content)

Best at short structured answers. For long reasoning, call a bigger model.
